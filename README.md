# Ozon-бот 1.2

Сотрудник присылает ссылку на товар Ozon → черновик → «Опубликовать» → администраторы
собирают корзину в «Сборке» и отмечают статусы. Парсинга страниц нет.
Заказ называется по заказчику: **«Фамилия Имя №номер»**, текст к ссылке становится комментарием.

Плюс заявки на помощь: сотрудник → мастер → оценка → отчёт.

## Запуск

```bash
pip install -r req.txt
python bot.py
```

База `data/bot.db` используется как есть. При запуске бот сам добавит недостающее:
колонки `orders.comment`, `orders.ordered_at`, `orders.qty_arrived` и новые таблицы `order_notices`, `repairs`.
Существующие записи не меняются.

## .env

Прежние: `BOT_TOKEN`, `DEVELOPER_IDS`, `ADMIN_CHAT_ID`, `WORK_CHAT_ID`, `TZ`, `DB_URL`,
`DEFAULT_DEADLINE_DAYS`, `BIG_ORDER_THRESHOLD`, `APPROVED_BY`.

Новые:

| Переменная | Что это |
|---|---|
| `REPAIR_CHAT_ID` | кто получает заявки на помощь (мастер; можно id группы) |
| `REPORT_CHAT_ID` | кому идут отчёты по заявкам и оценки (другой человек) |
| `DIGEST_HOUR` | час утренней сводки по будням, `off` — выключить |

Если `REPAIR_CHAT_ID` / `REPORT_CHAT_ID` пустые — всё идёт `ADMIN_CHAT_ID`.
Свой id человек узнаёт командой `/id`. Мастеру и получателю отчётов отдельно выдавать
доступ не нужно.

Больше не используются (можно удалить): `PARSE_*`, `PROXY`, `POLL_DURATION_HOURS`,
`DELETE_VOTES_NEEDED`.

## Роли

* **Администраторы и разработчики** — одинаковые права: каждый получает уведомление о
  новом заказе, меняет статусы, видит в меню «▤ Общий заказ» и «▤ Лаборатория», выдаёт права (`/grant`). Разработчиков
  из `.env` снять или заблокировать нельзя.
* **Сотрудники** видят статусы своих заказов, но не меняют их (только отмена, пока заказ
  в работе, и «Изменить», пока он ждёт оформления).

## Статусы

`✎ черновик → ○ ждёт оформления → ◐ заказано → ✓ приехал` (или `✕ отменён`).
На кнопке меню «В пути · N» — сколько заказов сотрудника ещё едет; приехал заказ — N
уменьшается.

**Приехала часть** (админы, если в пути больше одной штуки): «◑ Частично» на карточке
или уведомлении → сколько штук приехало → остаток «◐ Ждём» (заказ в пути, статус
`◑ приехало 2 из 5`) или «✕ Отменён Ozon» / «✕ Не нужен» (заказ закрыт как приехавший).
Если Ozon отменил весь заказ — «Отменить» → «✕ Отменён Ozon» (вариант только у админов).

## Общий заказ и Лаборатория — по датам

У админов и разработчиков в главном меню две отдельные кнопки: **«▤ Общий заказ»**
(Т4, ЦМНТ, ЦРПП) и **«▤ Лаборатория»** — это два разных заказа на Ozon, на одном экране
они не смешиваются. Команды: `/main`, `/lab`. Внутри — «Ждут оформления» или «Заказано». Заказы сгруппированы по датам (ждущие — по
дню публикации, заказанные — по дню заказа на Ozon). Нажмите на дату → «◐ Всё» / «✓ Всё»
(заказано / приехало) или отметьте часть галочками и «Выбранное». Заказчики получают по одному
сообщению со списком.

## Заявка на помощь

`Заявка на помощь` → «Новая заявка» → описание (можно с фото) → место → «Отправить мастеру».
У мастера кнопки «Взял в работу / Сделано / Отклонить». После «Сделано» заявитель ставит
оценку 1–5 (или возвращает «не решено»), отчёт с оценкой уходит в `REPORT_CHAT_ID`.
`/repstats` — сводка за 30 дней; по понедельникам получатель отчётов получает недельную.
